# ProsperCodeX

Personal professional portfolio for Odejotor Prosper Emuobohwo.

## Run locally (Windows PowerShell)

```powershell
py -m pip install -r requirements.txt
py app.py
```

Open http://127.0.0.1:5000

## Deploy on Render

Create a Python web service from this repository. Build command: `pip install -r requirements.txt`. Start command: `gunicorn app:app`.
